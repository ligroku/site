# Mihous documentation

Welcome to the Mihous documentation.

Mihous is a collection of open tools for people building creative systems around **light, audio, video and network control**.

The goal is simple:

> Make the technical part disappear.

## Documentation structure

Mihous documentation is organized by project and topic.

- [mroky](./mroky/index.md) — networking and control
- [Effects](./effects/index.md) — visual effects
- [Audio](./audio/index.md) — audio tools
- [Video](./video/index.md) — video tools
- [Guides](./guides/getting-started.md) — practical guides

## Adding documentation

Every Markdown file inside `docs/` is automatically discovered by the website.

You do not need to register a page in JavaScript.

Create:

```text
docs/effects/my-effect.md
```

write Markdown, commit it, push it, and it becomes available in the documentation.
