# Getting started

This guide will explain how to use Mihous libraries in a creative project.

## Repository

Clone the repository:

```bash
git clone https://github.com/ligroku/mihous.git
cd mihous
```

## Build

The build system is based on CMake.

```bash
cmake -S . -B build
cmake --build build
```
